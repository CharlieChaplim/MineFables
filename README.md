
# MineFables

Expansive Minecraft mod focused on playable characters,
factions, progression, abilities and custom gameplay systems.

## Technical Stack

- Minecraft: 1.21.1
- Mod Loader: NeoForge
- Java: 21
- Build System: Gradle

## Development

### Run the development client

```powershell
.\gradlew.bat runClient
```

### Build the mod

```powershell
.\gradlew.bat build
```

### Clean build

```powershell
.\gradlew.bat clean build
```
